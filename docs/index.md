<div class="hero-left" style="max-width: 85%; margin: 0 auto; padding: 20px; text-align: left;">
   <p class="hero-subtext"><a href="https://katana.network/">Katana</a> is an Ethereum Layer 2 built specifically for DeFi, designed to make capital more productive by concentrating liquidity and returning more of the value generated by the network back to users. Instead of spreading liquidity across competing protocols, Katana is built around a small set of core DeFi markets for trading, lending, and borrowing. Applications can then build on top of this shared liquidity, giving users access to deeper markets and allowing capital to be used more efficiently across the ecosystem.</p>
   <p class="hero-subtext">Katana also brings additional sources of revenue onchain, including sequencer fees, <a href="https://polygon.technology/blog/introducing-vaultbridge-a-new-revenue-lego-for-evm-chains/">Vault Bridge</a> yield, and stablecoin revenue. This revenue can be directed back into DeFi applications as incentives, helping increase yields without relying entirely on inflationary token emissions. For users, the goal is simple: deeper liquidity, more productive assets, and better sustainable yield.</p>
   <p class="hero-subtext">Katana uses <a href="https://agglayer.dev/">Agglayer</a> for interoperability and ZK proofs to secure state transitions, making it easier for users and assets to move between Katana and the broader Ethereum ecosystem.</p>
</p>
